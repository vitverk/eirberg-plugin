# Eirberg icon

`icon.svg` contains the original two-color Eirberg artwork. `icon.png` is a
transparent 512 × 512 RGBA export used by the plugin listing and composer.
It renders the SVG at 410 × 410 with 51 pixels of transparent padding on each
side, preserving the previous icon's size and position. The spaces inside the
mark are also transparent, so it works on light and dark surfaces.

Preserve the vector paths and brand colors (`#009ddd` and `#0060a9`) when exporting;
do not flatten the PNG onto a background. These assets identify Eirberg; their
existing ownership is unchanged.
